# acre-site-assets

Images for the acremortgage.com website, served through jsDelivr:

    https://cdn.jsdelivr.net/gh/albanhox/acre-site-assets@main/photos/<file>

`photos/*.jpg` are section photos (generated 2026-09-04), `photos/lo/*.jpg` are 96px loan officer headshots pulled from acremortgage.com profile pages. jsDelivr caches for up to 7 days; bump the commit ref in the URL (or purge at purge.jsdelivr.net) to force a refresh.
